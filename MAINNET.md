# Запуск на mainnet — инструкция для владельца проекта

Серверу нужны два **отдельных рабочих кошелька**. Их приватные ключи лежат только в настройках сервера (Render): сервер подписывает ими сам, без человека.

| кошелёк | зачем | сколько положить |
| --- | --- | --- |
| **Релеер** | платит сетевую комиссию за каждый клик игроков и газ выплат | 0.05 SOL (~5 000 кликов) |
| **Пул** | сюда приходят комиссии с торговли токеном, отсюда сервер раздаёт выплаты игрокам | 0.002 SOL (минимум, чтобы счёт существовал) |

**Не используй свой основной кошелёк.** Это «горячие» кошельки: ключ лежит на сервере, поэтому держи на них ровно столько, сколько нужно для работы.

## 1. Создать кошельки (Phantom)

1. Phantom → иконка аккаунта слева вверху → **Add / Connect Wallet** → **Create New Account**. Назови `Pixelglow Relayer`.
2. Так же создай второй: `Pixelglow Pool`.
3. Для каждого: **Settings → Manage Accounts →** нужный аккаунт → **Show Private Key** → введи пароль → скопируй ключ (длинная строка букв и цифр).

Ключи никому не пересылай, ни в мессенджерах, ни в чате с разработчиком. Они вставляются сразу в Render (шаг 3).

## 2. Пополнить

С любого своего кошелька: **0.05 SOL** на Relayer и **0.002 SOL** на Pool.

## 3. Render

Render → сервис `pixelglow` → **Environment** → **Edit** → удали старые переменные и добавь (кнопка **Add from .env**) содержимое `mainnet.env`, заменив:

- `ВСТАВЬ_КЛЮЧ_HELIUS` (в двух строках) — API-ключ с helius.dev;
- `ВСТАВЬ_ПРИВАТНЫЙ_КЛЮЧ_РЕЛЕЕРА` — приватный ключ `Pixelglow Relayer`;
- `ВСТАВЬ_ПРИВАТНЫЙ_КЛЮЧ_ПУЛА` — приватный ключ `Pixelglow Pool`.

**Save Changes.** Через пару минут сайт перезапустится уже на mainnet. В логах Render (вкладка **Logs**) будет видно `relayer <адрес> … SOL` и `pool <адрес> … SOL`: адреса должны совпасть с твоими кошельками.

## Режим теста: доступ по SOL

`GLOW_MINT=SOL` и `MIN_HOLD=0.01` значат: рисовать и получать выплаты может любой кошелёк, на котором есть хотя бы 0.01 SOL. Когда выйдет $GLOW: `GLOW_MINT=<mint-адрес токена>`, `MIN_HOLD=<сколько токенов нужно держать>`, а получателем creator fee на pump.fun указать адрес **Pool**.

## Безопасность

- Один клик стоит релееру 0.00001 SOL (две подписи по 5 000 лампортов). `RELAYER_DAILY_TX_CAP=4000` — не больше 4 000 кликов и ~0.04 SOL в сутки, даже если кто-то начнёт спамить; дальше клики до следующих суток отклоняются. Для запуска поднять лимит и пополнить релеер: 1 млн кликов ≈ 10 SOL.
- Все комиссии в Pool принадлежат холдерам: за сутки раздаётся `DRIP_PER_DAY` (по умолчанию 20%) от того, что лежит в пуле, понемногу каждые 10 минут. Остальное остаётся подушкой: если торговля затихнет, выплаты идут дальше из накопленного. Если часть комиссий должна идти проекту, задай `HOLDER_SHARE` (например 0.9) и `TREASURY_ADDRESS` — эта доля каждого нового поступления уйдёт туда, а на сайте нужно будет написать об этом открыто.
- Если ключ мог утечь: создай новый кошелёк, перенеси остаток, замени переменную в Render.

## Скорость: несколько RPC для отправки кликов

Каждый клик — отдельная транзакция, а бесплатный Helius принимает только 1 отправку в секунду. Сервер распределяет отправки по нескольким RPC и не превышает лимит ни одного (`SEND_RPS` — лимит основного `RPC_URL`, `SEND_RPC_URLS` — дополнительные адреса в формате `адрес|в_секунду` через запятую). Бесплатные ключи:

1. **Alchemy** — alchemy.com → Create new app → Solana, Mainnet → скопировать HTTPS-адрес `https://solana-mainnet.g.alchemy.com/v2/…`
2. **Chainstack** — chainstack.com (тариф Developer, без карты) → Create project → Join network → Solana Mainnet → Global node → Access & credentials → HTTPS endpoint `https://solana-mainnet.core.chainstack.com/…`

Вставить в Render переменную `SEND_RPC_URLS` (шаблон в `mainnet.env`). В `/api/stats` → `diag.send` видно, сколько отправок принял и отклонил каждый RPC; если у кого-то растёт `limited`, уменьши его число после `|`.
